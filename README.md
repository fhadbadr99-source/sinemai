# سينمائي — نشر الموقع مع حماية المفتاح

## الفكرة
موقعك (index.html) ما عاد يتكلم مع TMDB مباشرة، بل يتكلم مع ملف صغير
(api/tmdb.js) يعمل على السيرفر، وهو اللي يحتفظ بمفتاحك بشكل مخفي
تماماً عن الزوار.

## خطوات النشر على Vercel (مجاني)

1. روح إلى vercel.com وسجّل حساب (تقدر تسجل مباشرة بحساب GitHub).
2. ارفع هذا المجلد (index.html + مجلد api) إلى مستودع GitHub جديد،
   أو استخدم أداة Vercel CLI لرفعه مباشرة من جهازك بدون GitHub.
3. من لوحة تحكم Vercel اضغط "Add New Project" واختر المستودع
   (أو اسحب المجلد لو تستخدم الرفع المباشر).
4. قبل الضغط على Deploy، افتح قسم "Environment Variables" وأضف:
   - الاسم: TMDB_API_KEY
   - القيمة: مفتاحك من TMDB (API Key v3 auth)
5. اضغط Deploy. بعد دقيقة أو دقيقتين بيعطيك Vercel رابط جاهز
   مثل: https://your-site.vercel.app

من هذه اللحظة أي زائر يدخل الرابط، الموقع يشتغل له فوراً بدون
أي خانة إدخال مفتاح، والمفتاح نفسه غير موجود في أي كود يصل للمتصفح.
